# Advanced Country Field

Advanced Country Field is a Drupal module that provides an enhanced country field with additional functionality.

## Requirements

- Drupal 10 or 11
- PHP 8.1 or higher

## Installation

### Using Composer (Recommended)

```bash
composer require drupal/advanced_country_field
```

### Manual Installation

1. Clone this repository into your Drupal installation:
   ```bash
   git clone https://github.com/ilyas2017/advanced-country-field.git modules/contrib
   ```

2. Enable the module via Drush:
   ```bash
   drush en advanced_country_field -y
   ```
   Or via the admin interface at `/admin/modules`
